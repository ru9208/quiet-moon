## 世界规则一句话

安静为主；满月才恢复刷怪与肉食繁殖。饥饿绑定僵尸，炼药做成炖汤，钓鱼写成附魔，村民按群系收鱼。

Calm by default. Full moon restores spawns and meat-animal breeding. Hunger gates zombies, potions become stews, fishing writes enchantments, villagers buy biome fish.
