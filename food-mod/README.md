# 食物包 / Food Add-on

Minecraft Bedrock 附加包。当前版本 **v1.0.48**（引擎 **1.21.130+**）。

安静生存：非满月停止新刷怪；饥饿、炼药炖汤、怪物氛围。与 [附魔鱼 / 宠物包](../fish-mod/README.md) 一起构成 My Pack 世界规则。

Quiet survival for Bedrock: no new spawns on a quiet moon; hunger, potion stews, atmospheric mobs. Pair with the Enchant Fish & Pets pack.

## 安装 / Install

1. 下载 `Food_v1.0.48.mcaddon`
2. 用 Minecraft 打开导入
3. 世界设置中启用本包；需允许脚本（Beta APIs / 脚本）
4. 若世界里已有旧版食物包，先关掉再导入

## 要点 / Highlights

- 非满月整天（含下界、末地）**停止新刷怪**；满月恢复刷怪与已保存的战斗难度
- 僵尸族仅在饥饿 **≤3 格（6 点）** 时追玩家
- 苦力怕见冲刺才怒；蜘蛛只在低亮度攻击；恶魂见弓/弩/三叉戟才主动喷火
- 10 种药水炖汤；熟肉不可堆叠；非满月肉食动物不能繁殖
- 跳夜：清空饱和 + 饥饿 I 120 秒；鸡下蛋约 20–40 分钟一枚
